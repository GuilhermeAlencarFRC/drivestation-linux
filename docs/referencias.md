# Referências técnicas

Fontes consultadas em 5 de novembro de 2026. Os links `stable` e `latest` podem
mudar; cada implementação deve registrar a versão pertinente à sua referência.

## NI Driver Station para roboRIO

- [FRC Driver Station Powered by NI LabVIEW](https://docs.wpilib.org/en/stable/docs/software/driverstation/driver-station.html)
  — referência de interface e comportamento.
- [WPILib instalada localmente, versão 2026.2.1](https://github.com/wpilibsuite/allwpilib/releases/tag/v2026.2.1)
  — referência de versão para o ambiente de desenvolvimento existente;
  isso não identifica a versão do aplicativo da NI.

## Nova Driver Station para Systemcore

- [The 2027 FIRST Driver Station](https://wpilib.org/blog/the-2027-first-driver-station)
  — anúncio oficial que distingue suporte a Linux, alvo Systemcore e ausência
  de compatibilidade com os sistemas anteriores.
- [FirstDriverStation-Public](https://github.com/wpilibsuite/FirstDriverStation-Public)
  — distribuição e informações públicas da nova aplicação.

## Uso das fontes

Os documentos acima orientam o levantamento de requisitos. Eles não demonstram
que este projeto tenha implementado ou testado qualquer funcionalidade.

Capturas, nomes e recursos de terceiros devem ter origem e permissão de uso
avaliadas antes de serem incorporados. Não há imagens, binários ou código da
NI redistribuídos neste repositório inicial.
